# Plotting

```{eval-rst}
.. automodule:: factominer.plot
   :members:
```

The matplotlib backend reproduces FactoMineR's `plot.PCA` / `plot.CA` /
`plot.MCA` / `plot.HCPC` layouts: individuals factor map (with optional
`habillage` coloring, confidence ellipses, and `invisible` filtering),
variables factor map (correlation circle for PCA; arrows for CA/MCA),
biplot, scree plot, contributions bars, dendrogram, and the per-cluster
factor map.

The plotly backend is deferred to Round 2.
